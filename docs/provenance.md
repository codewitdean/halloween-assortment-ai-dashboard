# Provenance rules

| Label             | Meaning                                                    | Current use                                                                          |
| ----------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Historical Fact   | Supplied current attributes, performance and reviews       | Current source records; no new history is manufactured                               |
| Calculated Metric | Independent arithmetic from validated inputs               | Counts, costs, margins, unit shares, facing efficiency and scenario agreement counts |
| Vendor Claim      | Supplied new terms and marketing                           | New price/cost/minimum/footprint/license terms and verbatim vendor claims            |
| Model Assumption  | An explicitly illustrative input                           | Half-price illustration and literal workbook base demand/clearance inputs            |
| AI Interpretation | Evidence explanation requiring human review                | Generated draft summaries and Q&A caveats, with actual provider mode disclosed       |
| Team Decision     | Approved business placement or explicitly approved wording | Imported J7:J32 consensus and locally reviewed rationales                            |

Product data is sourced only from Source data. A separate narrow importer reads literal Product decisions A/C/H/I/J fields for identities, comparison placements and approved consensus. A separate model importer reads literal Assumptions!B7:D7, B13:B15 and A21:B46. Cached formula outputs, narrative recommendation cells and member claims are not calculation inputs.

Historical financial summaries are explicitly labeled historical. Projected summaries are explicitly modeled Calculated Metrics using Source data and Model Assumptions. New-product full-price margin is not a realized margin. Half-price clearance is illustrative, not a prediction of prices, sold quantities or recoveries. Scenario names are workbook labels, not a claim that this app optimized them.

Merchant notes are source annotations reproduced verbatim with a qualitative-commentary notice. Their authorship is not established. The app does not invent a member or AI author. The Sitcom/Reaper footprint conflict remains visible with numeric source facings preserved.

Draft rationales are generated from objective evidence and limitations. They are not historical records of why particular team members chose something. Approval of a rationale is a separate explicit UI action and never changes the approved placement. The app does not equate a saved rationale approval with individual votes.

The UI includes UTC import time, SHA-256 workbook identity, Source data cell references and authoritative decision-cell references. Referenced original source workbook ranges remain unverified because that workbook and the original event PDF were not provided.
